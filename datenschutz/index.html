Datenschutz.
Klar erklärt.

Diese Hinweise erklären, welche Personendaten beim Besuch von heav.ch und bei einer Projektanfrage bearbeitet werden.

Verantwortlich

Verantwortlich für die Bearbeitung von Personendaten auf dieser Website ist HEAV, Inhaber und Gründer Michias Tegegne, Schweiz. Datenschutzanfragen können an hello@heav.ch gerichtet werden.

Besuch der Website

Die Website wird über GitHub Pages bereitgestellt. Beim Aufruf kann GitHub technische Daten verarbeiten, insbesondere IP-Adresse, Zeitpunkt, aufgerufene Adresse, Browsertyp und User-Agent. Diese Bearbeitung dient der sicheren und stabilen Auslieferung der Website.

Weitere Angaben enthält die Datenschutzerklärung von GitHub.

Kontaktformular und FormSubmit

Bei einer Projektanfrage werden die von dir eingegebenen Angaben bearbeitet. Dazu können Name, Firma, E-Mail-Adresse, Telefonnummer, Projektart, gewünschter Zeitraum und Projektbeschreibung gehören. Pflichtfelder sind im Formular gekennzeichnet.

Das Formular wird über FormSubmit an hello@heav.ch übermittelt. FormSubmit erhält die Formulardaten als technischer Empfänger. Die Bearbeitung erfolgt, um deine Anfrage zu beantworten, ein mögliches Projekt zu beurteilen und die nächsten Schritte zu besprechen.

Die Übermittlung erfolgt erst nach deiner ausdrücklichen Einwilligung im Formular. Weitere Angaben enthält die Datenschutzerklärung von FormSubmit.

Speicherdauer

Angaben aus Anfragen werden so lange aufbewahrt, wie dies für die Bearbeitung, die weitere geschäftliche Kommunikation und allfällige gesetzliche Aufbewahrungspflichten erforderlich ist. Nicht mehr benötigte Angaben werden gelöscht oder anonymisiert.

Bearbeitung im Ausland

GitHub und FormSubmit können Daten ausserhalb der Schweiz bearbeiten, insbesondere in den USA. Dort kann ein anderes Datenschutzniveau gelten. Einzelheiten zur Bearbeitung und zu den Schutzmassnahmen ergeben sich aus den oben verlinkten Erklärungen der Anbieter.

Lokale Browserdaten

HEAV setzt keine Analyse- oder Marketing-Cookies ein. Die Website verwendet den Sitzungsspeicher des Browsers ausschliesslich für den einmaligen Logo-Opener und für den Status einer Formularübermittlung. Diese Daten bleiben auf die jeweilige Browsersitzung beschränkt.

Videos von YouTube

Auf einzelnen Projektseiten können Filme über YouTube gezeigt werden. Die Verbindung zu YouTube wird erst hergestellt, wenn du den Video-Player ausdrücklich aktivierst. Dabei können insbesondere deine IP-Adresse und technische Nutzungsdaten an Google/YouTube übermittelt und dort auch ausserhalb der Schweiz bearbeitet werden.

Die Einbettung verwendet die Domain youtube-nocookie.com. Weitere Informationen enthält die Datenschutzerklärung von Google.

Betroffenenrechte

Nach Massgabe des anwendbaren Datenschutzrechts kannst du Auskunft über deine Personendaten sowie deren Berichtigung oder Löschung verlangen. Soweit anwendbar, kannst du zudem die Bearbeitung einschränken lassen, ihr widersprechen oder die Herausgabe bestimmter Daten verlangen. Anfragen bitte an hello@heav.ch.
