# HEAV

Official multi-page website for [heav.ch](https://heav.ch).

## Structure

- `/` — Home
- `/leistungen/` — Film production services
- `/arbeiten/` — Selected work and visual studies
- `/ueber-uns/` — About HEAV
- `/michias-tegegne/` — Founder and owner profile
- `/kontakt/` — Contact

The site is static, dependency-free at runtime, responsive, and deployed through GitHub Pages. SEO metadata, structured data, `robots.txt`, and `sitemap.xml` are included.
